## What's New in v3.1.0

### ✨ New Features
- **Guest Demo Mode** — Users can now explore the app without an account. A "Try Demo" option on the login screen launches a fully interactive session with simulated data, making it easy to evaluate Dimmo before connecting real hardware.

### 🎨 UI / UX Improvements
- Refreshed **Dashboard screen** layout with improved information hierarchy and cleaner card design.
- Login screen updated to surface the new guest demo entry point prominently.

### 🌐 Localization
- Added missing translation keys to `app_translations.dart` to prevent untranslated string fallbacks.

### 🛠 Build & Infrastructure
- Bumped **Gradle wrapper to 9.3.1** to meet Flutter's minimum Gradle requirement and fix CI builds.
- Updated project README with a new app preview image and revised setup documentation.

---

### 📦 Installation
Download `dimmo-v3.1.0.apk` below and install it on your Android device.  
You may need to enable **Install from unknown sources** in your device settings.

> **Minimum Android version:** as defined in `minSdk` (see `build.gradle.kts`)  
> **Built with:** Flutter stable channel · Gradle 9.3.1 · AGP 9.0.1 · JDK 17
